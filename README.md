# Image Gallery App
## Project Overview
A simple Android app developed using Kotlin and XML for the Veda Technology Android Development Track (Day 17). It displays multiple images in a grid-like arrangement.
## Technologies Used
- Kotlin
- XML Layouts
- Android Studio
## Features
- Displays a grid of images
- Uses ScrollView for scrolling
- Uses GridLayout for the grid structure
## How to Run
1. Clone the repository. 2. Open in Android Studio. 3. Sync Gradle. 4. Run the app.
## Outcome
The application successfully displays multiple images in a clean grid layout.
